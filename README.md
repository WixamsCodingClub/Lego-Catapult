# Lego Catapult for the BBC micro:bit

The Wixams Coding Club uses the [32-in-1 Wonder Building Kit from ElecFreaks](https://shop.elecfreaks.com/products/elecfreaks-micro-bit-32-in-1-wonder-building-kit-without-micro-bit-board) as a tool for learning programming on the BBC micro:bit. The Lego Catapult project started with the [The Stone Thrower](https://wiki.elecfreaks.com/en/microbit/building-blocks/wonder-building-kit/Wonder-Building-Kit-case-29) case from ElecFreaks.

![Image of The Stoner Thrower project from ElecFreaks](/assets/ElecFreaks-32-in-1-Case-29-The-Stone-Thrower.png)

It was then updated to add additional functionality and to be controlled remotely using the [Kitronik :GAME ZIP 64 for the BBC micro:bit](https://kitronik.co.uk/products/5626-game-zip-64-for-the-bbc-microbit).

# How it Works

The original project had two basic functions:

* Press button A to move the catapult forwards for a set time.
* Press button B to move the arm and propel the 'stone' (another Lego piece).

Some changes were made to the Lego build itself, to improve its strength and reliability. Then, using the :GAME ZIP 64 controller, the following improvements were made to the functionality:

1. The catapult can be controlled remotely and driven forwards and backwards. This uses the Up and Down buttons on the controller joypad.
2. The arm can be fired remotely using the Fire 1 button on the controller.
3. When the catapult is fired the controller displays an animation and plays a short tune.
4. The speed at which the catapult moves forwards and backwards can be toggled between slow and fast by pressing the Fire 2 button on the controller.
